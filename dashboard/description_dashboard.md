# Description du dashboard

Le dashboard final a été conçu pour répondre à une logique opérationnelle simple :

- choisir un jour de semaine ;
- choisir une heure ;
- identifier les stations qui se vident ;
- identifier les stations qui saturent ;
- afficher une action recommandée.

## Composants

- KPI : stations analysées, stations prioritaires
- Top stations qui se vident
- Top stations qui saturent
- Carte des stations prioritaires
- Tableau opérationnel
- Bloc de lecture opérationnelle

## Usage

Exemple :
- Monday + 08
- Friday + 17
